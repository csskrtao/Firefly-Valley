# 萤石谷 · Firefly Valley

像素风格的农场生活 + 地下城 RPG，灵感来自《星露谷物语》。白天种田、和镇民打交道，晚上下矿打怪，把矿石交给铁匠一阶一阶升级装备，挑战矿脉深处的守层者。

## 游戏内容（第一章）

- **职业**：战士、法师、刺客；击败第一个守层者后解锁隐藏职业「萤灵使」。每个职业有 3 种武器、3 个技能（1 / 3 / 6 级解锁）
  - 战士：剑 / 战斧 / 长枪，技能旋风斩、冲锋、战吼
  - 法师：法杖 / 魔导书 / 法球，技能冰霜新星、火球术、闪现
  - 刺客：匕首 / 双刃 / 飞镖，技能影步、飞刀扇、毒刃
  - 萤灵使：萤灯 / 萤铃 / 萤蝶扇，技能萤光爆发、萤灵增殖、星辉之雨
- **等级**：打怪得经验，最高 20 级，每级加生命和攻击
- **人物**：所有角色都是按部件拼出来的 16×28 像素小人，有四个方向的走路动画；职业换上更好的护甲时外观也会变（护肩、胸甲）
- **小镇**：84×56 格的大地图，有农场、商店街、喷泉广场、东边的森林、西南的湖和沙滩、河上的木桥，晚上路灯会亮
- **镇民**：铁匠老岩、杂货店薇拉、药剂师莉娅、公会的艾恩、猫头鹰咕咕、孩子小橡。每个人有自己的日程，会走去广场吃午饭、去湖边散步、晚上回家。聊天和送礼提升好感，到一定心数会触发剧情并解锁奖励
- **农场**：锄地、播种、浇水、收获。春夏秋各有两种作物，换季时过季作物会枯萎；下雨天自动浇水
- **采集**：森林、草地和沙滩每天会长出当季的野菜、蘑菇、浆果、贝壳，一共 10 种
- **做饭**：在家里的灶台上用作物和采集物做 10 道料理，吃了有几个小时的加成（移速、攻击、防御、暴击、回血、光照）
- **饰品**：10 种戒指、护符、吊坠，可以同时戴两件；从宝箱、守层者和镇民的好感奖励里获得
- **委托**：冒险者公会按顺序发布 7 个讨伐 / 收集 / 守层者委托
- **装备**：木 → 铜 → 铁 → 金 → 萤石 五阶武器和护甲，每阶可强化到 +10；新武器的图纸可以在铁匠铺买，也会在宝箱里出现
- **矿脉**：10 层，分「苔藓矿道」和「锈铁坑道」两个区域，6 种怪物，普通楼层有几率出现宝箱；第 5 层守层者「史莱姆王·咕噜噜」，第 10 层守层者「铁颚掘地者」
- **时间**：昼夜变化，凌晨两点前要回家睡觉；睡觉自动存档
- **存档**：3 个存档位，存在浏览器本地，旧版本的存档会自动升级
- **音乐和音效**：全部用 WebAudio 实时合成

## 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（贴着墙角走会自动滑过去） |
| Shift | 按住跑步 |
| J / 空格 | 使用当前工具（锄地、浇水、播种、挖矿） |
| K | 普通攻击（按住连续攻击） |
| L / U / O | 第 1 / 2 / 3 个技能 |
| E / 回车 | 对话、进门、开宝箱、采集、上下楼、收获 |
| 1–5 / Tab | 切换工具；再按一次 3 切换种子 |
| Q | 喝药水，没有就吃作物或采集物 |
| I / B | 背包、装备（换武器类型、戴饰品）、人物关系、委托 |
| Esc / P | 暂停菜单（存档、设置、回到标题） |

手机和平板会显示虚拟摇杆和按键，摇杆推到底就是跑步，横屏竖屏都可以玩。

## 开发

需要 Node.js 20 以上。

```bash
npm install
npm run dev        # 本地开发，打开终端里显示的地址
npm test           # 单元测试
npm run typecheck  # 类型检查
npm run build      # 打包到 dist/
npm run preview    # 预览打包结果
```

开发模式下可以在浏览器控制台用 `fireflyValley.game.current` 拿到当前场景，方便调试，例如 `fireflyValley.game.current.goToFloor(5)`。

## 部署

推送到 `main` 后，GitHub Actions 会自动检查、测试、打包并发布到 GitHub Pages。第一次需要在仓库的 **Settings → Pages** 里把 **Source** 设为 **GitHub Actions**。

## 项目结构

```
src/
  core/      引擎：主循环、渲染、输入、音频、镜头、本地存储
  data/      游戏数据：物品、作物、职业、武器类型、技能、菜谱、装备、怪物、楼层、NPC、委托
  state/     存档结构、新存档、旧存档迁移
  systems/   纯逻辑：种田、锻造、好感、委托、买卖、属性、时间、等级、采集、做饭、宝箱
  world/     地图：小镇地形、矿脉楼层生成
  gfx/       像素图（全部用代码绘制，没有图片文件），人物用部件拼装
  entities/  玩家、NPC、矿石、怪物、Boss
  ui/        DOM 界面：HUD、对话框、面板、设置
  scenes/    标题画面和游戏场景（play/ 下按功能拆分）
tests/       Vitest 单元测试
docs/        设计文档和架构说明
```

更详细的说明见 [docs/架构说明.md](docs/架构说明.md)，完整的游戏设计见 [docs/游戏设计文档.md](docs/游戏设计文档.md)。
