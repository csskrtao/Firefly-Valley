# 萤石谷 · Firefly Valley

像素风格的农场生活 + 地下城 RPG，灵感来自《星露谷物语》。白天种田、和镇民打交道，晚上下矿打怪，把矿石交给铁匠一阶一阶升级装备，挑战矿脉深处的守层者。

## 游戏内容（第一章）

- **职业**：战士（旋风斩）、法师（冰霜新星）、刺客（影步）；击败第一个守层者后解锁隐藏职业「萤灵使」
- **农场**：锄地、播种、浇水、收获。春夏秋各有两种作物，换季时过季作物会枯萎；下雨天自动浇水，冬天地里种不了东西
- **小镇**：铁匠老岩、杂货店薇拉、药剂师莉娅、公会的艾恩、猫头鹰咕咕、孩子小橡。聊天和送礼提升好感，到一定心数会触发剧情并解锁折扣、强化加成等奖励
- **委托**：冒险者公会按顺序发布 7 个讨伐 / 收集 / 守层者委托
- **装备**：木 → 铜 → 铁 → 金 → 萤石 五阶武器和护甲，每阶可强化到 +10（+3 以后有失败率，失败不掉级）
- **矿脉**：10 层，分「苔藓矿道」和「锈铁坑道」两个区域，6 种怪物；第 5 层守层者「史莱姆王·咕噜噜」，第 10 层守层者「铁颚掘地者」
- **时间**：昼夜变化，凌晨两点前要回家睡觉；睡觉自动存档
- **存档**：3 个存档位，存在浏览器本地
- **音乐和音效**：全部用 WebAudio 实时合成

## 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| J / 空格 | 使用当前工具（锄地、浇水、播种、挖矿） |
| K | 普通攻击（按住连续攻击） |
| L | 职业技能 |
| E / 回车 | 对话、进门、上下楼、收获 |
| 1–5 / Tab | 切换工具；再按一次 3 切换种子 |
| Q | 喝药水，没有就吃作物 |
| I / B | 背包、装备、人物关系、委托 |
| Esc / P | 暂停菜单（存档、设置、回到标题） |

手机和平板会显示虚拟按键，横屏竖屏都可以玩。

## 开发

需要 Node.js 20 以上。

```bash
npm install
npm run dev        # 本地开发，打开终端里显示的地址
npm test           # 单元测试
npm run typecheck  # 类型检查
npm run build      # 打包到 dist/
npm run preview    # 预览打包结果
```

开发模式下可以在浏览器控制台用 `fireflyValley.game.current` 拿到当前场景，方便调试，例如 `fireflyValley.game.current.goToFloor(5)`。

## 部署

推送到 `main` 后，GitHub Actions 会自动检查、测试、打包并发布到 GitHub Pages。第一次需要在仓库的 **Settings → Pages** 里把 **Source** 设为 **GitHub Actions**。

## 项目结构

```
src/
  core/      引擎：主循环、渲染、输入、音频、镜头、本地存储
  data/      游戏数据：物品、作物、职业、装备、怪物、楼层、NPC、委托
  state/     存档结构、新存档、旧存档迁移
  systems/   纯逻辑：种田、锻造、好感、委托、买卖、属性、时间
  world/     地图：小镇地形、矿脉楼层生成
  gfx/       像素图（全部用代码绘制，没有图片文件）
  entities/  玩家、NPC、矿石、怪物、Boss
  ui/        DOM 界面：HUD、对话框、面板、设置
  scenes/    标题画面和游戏场景（play/ 下按功能拆分）
tests/       Vitest 单元测试
docs/        设计文档和架构说明
```

更详细的说明见 [docs/架构说明.md](docs/架构说明.md)，完整的游戏设计见 [docs/游戏设计文档.md](docs/游戏设计文档.md)。
