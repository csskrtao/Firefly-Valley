# 萤石谷 · Firefly Valley

像素风格的农场生活 + 地下城 RPG，灵感来自《星露谷物语》。白天种田、和镇民打交道，晚上下矿打怪，把矿石交给铁匠，一阶一阶升级装备，最后挑战 Boss。

## 怎么玩

用浏览器直接打开 `index.html` 就能玩，不需要安装任何东西。存档保存在浏览器本地。

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| J / 空格 | 使用当前工具（锄地、浇水、播种、挖矿） |
| K | 普通攻击 |
| L | 职业技能 |
| E / 回车 | 对话、进门、上下楼、收获 |
| 1–5 / Tab | 切换工具 |
| Q | 喝药水，没有就吃作物 |

手机上会显示虚拟按键。

## 原型内容

- **职业**：战士（旋风斩）、法师（冰霜新星）、刺客（影步）；击败史莱姆王后解锁隐藏职业「萤灵使」
- **农场**：锄地、播种、浇水，萝卜和光莓两种作物，出货箱卖菜
- **NPC**：铁匠老岩（锻造与强化）、杂货店薇拉（种子与药水）、猫头鹰咕咕（提示）
- **装备**：木 → 铜 → 铁 → 金 四阶武器和护甲，可强化到 +5
- **矿脉**：3 层，史莱姆、蝙蝠、骷髅；第 3 层 Boss 史莱姆王·咕噜噜
- **昼夜**：时间流逝、夜晚变暗、凌晨两点前要回家睡觉
