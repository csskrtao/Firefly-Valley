# 架构说明

萤石谷用 TypeScript + Vite 构建，没有使用游戏引擎。画面是 Canvas 2D，界面是普通 DOM，音频是 WebAudio 实时合成。下面按依赖方向从底层到上层介绍。

## 分层

```
scenes  ──▶  entities / ui / gfx  ──▶  world / systems  ──▶  state / data  ──▶  core
```

- **data**：只有常量和类型，例如 `ITEMS`、`CROPS`、`CLASSES`、`WEAPON_TYPES`、`SKILLS`、`RECIPES`、`ZONES`。加新物品、新作物、新怪物、新武器类型，基本只需要改这里。
- **state**：`SaveData` 是一个存档的全部内容，可以直接 JSON 序列化。`migrate()` 负责把旧版本存档补全成当前版本，改存档结构时记得同时更新 `SAVE_VERSION` 和 `migrate()`。
- **systems**：围绕 `SaveData` 的纯函数，例如 `till / plant / advanceDay`、`forge / enhance`、`gift / pendingHeartEvent`、`gainXp`、`spawnForage / pickForage`、`cook / applyDishBuff`、`rollChest / applyLoot`。`stats.ts` 把职业、武器阶级和类型、等级、饰品、料理加成合成最终的攻击、防御、移速等数值。不碰 DOM，需要随机的地方都可以把随机数当参数传进来，所以可以在 Node 里直接测试。
- **world**：`buildOverworld()` 生成 84×56 的小镇地图，同时给出建筑、告示牌、路灯、采集点和通往其他区域的路口；`regions/` 是世界地图上的区域（见下面「区域和世界地图」）；`generateFloor(floor, rand)` 生成矿脉楼层（含宝箱），保证每个格子都能从出生点走到；`findPath()` 是 NPC 用的广度优先寻路。
- **gfx**：所有像素图用字符串数组加调色板生成，或者直接用 Canvas 绘制，结果缓存成离屏画布。
  - `character.ts` 是人物生成器：给一个 `Look`（肤色、发型、帽子、上衣、裙子或袍子、护肩、胸甲、围巾等），画出 16×28 的正面、背面、侧面各 4 帧走路动画和对话头像。侧面只画朝右的，朝左时水平翻转。
  - `people.ts` 定义每个镇民和每个职业的 `Look`，`playerChar(cls, armorTier)` 按护甲阶级加护肩、胸甲。
  - `decor.ts` 是大树、灌木、石头、路灯、告示牌、长椅、沙滩、木桥、采集物和宝箱的图。
- **entities**：`Enemy` 是怪物和 Boss 的基类。敌人通过 `EnemyHost` 接口拿到移动、伤害、生成小怪等能力，不直接依赖场景。`Npc` 按 `data/npcs.ts` 里的日程（几点去哪个格子）寻路走过去，到了以后在附近小范围闲逛，玩家靠近时会转身看过来。
- **ui**：`UI` 管对话框（排队、打字机效果、选项）、大面板（分页）、黑屏过场和提示；`Hud` 管血条、时间、工具栏和 Boss 血条。菜单都支持键盘（`NavList`）、鼠标和触屏。
- **scenes**：`TitleScene`（标题、存档位、职业选择）和 `PlayScene`（地面上的各个区域和矿脉）。`PlayScene` 本身只负责主循环、碰撞、地图切换和一天的结束，具体功能拆在 `scenes/play/` 里：
  - `actions.ts` 工具、交互、开宝箱、采集、吃药和料理
  - `combat.ts` 攻击（按武器类型分挥砍、重劈、突刺、双刃、各种弹体）、12 个技能、经验、受伤
  - `town.ts` 各个 NPC 的对话和商店、家里的睡觉和做饭菜单
  - `menus.ts` 背包、装备页（换武器类型、戴饰品、看技能）和暂停菜单
  - `render.ts` 绘制
  - `fx.ts` 粒子、飘字、冲击波
  - `regions.ts` 野外区域的刷怪、区域 Boss、采集物刷新和交互；`regionFx.ts` 各区域的气氛效果（雾、星光、微光、风）
  - `worldmap.ts` 世界地图面板和快速旅行
  - `explore.ts` 户外探险：户外怪物和精英营地、挖宝、推石头、点火盆、隐藏宝箱、流浪商人和受伤的旅人、背包里的收集册。数据在 `data/treasure.ts`，规则（挖宝掉落、藏宝图、事件奖励、收集进度）在 `systems/explore.ts`，地图上的布置在 `world/exploreSites.ts`

## 主循环

`Game` 每帧调用当前场景的 `update(dt)` 和 `render()`，然后清空这一帧的按键。`dt` 上限 50ms，切到后台再回来不会瞬移。

`PlayScene.update` 的顺序：

1. 更新特效、镜头、UI。如果这一帧开始时有弹窗（对话框、面板）或正在黑屏过场，就不处理游戏输入，避免关闭对话框的那一下按键又触发一次交互。
2. 推进游戏时间（现实 1 秒 = 游戏 2.2 分钟），到凌晨 2 点强制结束这一天。
3. 玩家移动和操作。移动用速度平滑（起步和停下各约 0.1 秒），对角线归一化；撞到墙角时如果只差几个像素，会把玩家往旁边推一点让他滑过去。走路动画按实际走过的距离推进，所以跑步时脚步更快。触屏摇杆给出 0–1 的力度，推到底就是跑步。
4. 小镇里更新 NPC；野外区域和矿脉里更新敌人、弹体、萤灵和地面危险区。地面上走到地图最边上的路口就切换到相邻区域。

## 区域和世界地图

地面上分成 5 个区域：萤石镇（`town`）和雾语森林、星湖湿地、北山岩地、古代遗迹四个野外区域。矿脉是萤石镇下面的地下区域，还是用 `mineGen` 一层层生成。

- `world/regions/defs.ts` 是区域数据：名字、介绍、世界地图上的位置、主题色、怪物强度（`tier`，相当于矿脉第几层）、四条边分别通往哪个区域（`links`）、开放条件（等级、打倒哪个守层者）、怪物权重和区域 Boss。
- `world/regions/layout.ts` 把每个区域变成一个 `RegionLayout`：地图、路口、快速旅行落脚点、萤石路标、路牌、采集点、刷怪点、Boss 位置，以及留给户外探险用的 `digSpots`（可以挖宝的地方）和 `chestSpots`（可以放宝箱的角落）。小镇的 `townLayout()` 直接包一层 `buildOverworld()`；野外区域由 `buildWild()` 生成：先铺主题地形（水塘、山崖、废墟院子），再从每个路口开一条弯弯曲曲的小路到中间的路标、从路标开一条到 Boss 空地，然后在剩下的空地上放树和石头，最后把走不到的地方封掉。地图用固定种子生成，每次都一样，第一次用到时缓存。
- `systems/regions.ts` 是纯逻辑：去过哪些区域、开放条件、能不能快速旅行、区域 Boss 今天还在不在、采集物在存档里的键（野外区域的键前面带 `区域id:`）。
- `PlayScene` 的 `mode` 是 `town`、`wild` 或 `mine`，`region` 是当前（或下矿前所在）的地面区域，`area` 是它的 `RegionLayout`。`enterRegion()` 负责换区域：刷怪、放 Boss、把还没开放的路口标成路障。走到地图最边上的路口就进入相邻区域，出现在对面区域相应路口往里两格的地方；`fastTravel()` 花 30 分钟游戏时间传送到目标区域的萤石路标旁边。
- 区域 Boss 是 `entities/RegionBoss.ts`：沿用一种普通怪物的行为和像素图，碰撞框和画面都放大两倍，血量和攻击单独给。打倒后当天不再出现，第一次打倒有额外奖励。
- 存档里加了 `regions`（去过的区域）和 `regionBosses`（每个区域 Boss 上一次被打倒是第几天），老存档读进来时由 `migrate()` 补成默认值。

## 渲染

世界先画到 480×270 的离屏缓冲，再整块放大到屏幕上的画布，所以像素边缘不会有缝。地面图块先画；人物、怪物、大树、路灯、建筑按脚底的 y 坐标排序后一起画，所以人可以走到树和房子的后面。伤害数字和楼层名直接画在高分辨率的主画布上，保持清晰。夜晚和矿脉里的光照是另一张离屏画布：先铺一层暗色，再用 `destination-out` 在玩家、萤石、Boss 周围挖出亮光，路灯和窗户再叠一层暖色。

## 存档

存档在 `localStorage`，键名前缀 `firefly-valley:`：

| 键 | 内容 |
|---|---|
| `slot0`–`slot2` | 三个存档位的 `SaveData` |
| `settings` | 音量、震屏、伤害数字 |
| `unlocks` | 跨存档的解锁，例如隐藏职业 |

存档不记录玩家位置，读档后总是从家门口出发。第 3 版存档加了等级、武器类型、饰品、采集物和料理加成；地图扩大后农田整体挪了一格，`migrate()` 会把第 2 版存档里的田地坐标一起挪过去。睡觉、锻造、交委托时会自动存档，暂停菜单也可以手动存档。

## 测试

`tests/` 下是 Vitest 单元测试，覆盖种田、锻造强化、好感、委托、买卖、存档迁移、日历、等级、采集、做饭、宝箱掉落，矿脉生成（每一层用 40 个固定种子检查楼梯、Boss 出口和所有物件都能走到），以及小镇地图（采集点、告示牌、路灯都走得到，每个镇民的日程都找得到路）和野外区域（区域之间双向连通，每个路口、落脚点、路标、Boss 和采集点都走得到，开放条件和快速旅行规则）。

## 加内容的常见改法

- **新作物**：在 `data/items.ts` 加种子和作物，在 `data/crops.ts` 加作物定义；杂货店会按季节自动上架。
- **新怪物**：在 `data/monsters.ts` 加定义（可以复用现有 AI），在 `gfx/sprites.ts` 加像素图，然后加到 `data/floors.ts` 某个区域的怪物权重里。
- **新的地面区域**：在 `world/regions/defs.ts` 的 `REGIONS` 里加一项，并在相邻区域的 `links` 里连上它（两边都要连）；在 `world/regions/layout.ts` 的 `THEMES` 里写它的地形。`tests/regions.test.ts` 会检查路口、Boss 和采集点都走得到。
- **新的矿脉区域和 Boss**：在 `data/floors.ts` 的 `ZONES` 里加一段楼层，Boss 写成 `Enemy` 的子类放进 `entities/bosses.ts`，再在 `PlayScene.loadFloor` 里按 id 创建。
- **新 NPC**：在 `data/npcs.ts` 加定义和日程，在 `gfx/people.ts` 给它配一个 `Look`，在 `scenes/play/town.ts` 的 `talkTo` 里接上它的菜单。
- **新武器类型**：在 `data/weapons.ts` 加一项（职业、各阶名字、攻击方式、倍率、图纸价格），在 `scenes/play/render.ts` 的 `heldWeapon` 里画出它拿在手上的样子。
- **新料理**：在 `data/items.ts` 加一道 `dish`（带 `buff`），在 `data/recipes.ts` 写上配方。
- **新的挖宝点、隐藏宝箱、随机事件地点**：改 `data/treasure.ts` 里的坐标和奖励，`tests/explore.test.ts` 会检查这些地方都走得到、石圈能解开。
- **新饰品**：在 `data/items.ts` 加一件 `accessory`（带 `acc` 加成），再放进 `systems/loot.ts` 的宝箱表或者某个 NPC 的好感奖励里。
